# Transaction Analyzer

Приложение для анализа банковских транзакций из Excel-файлов.

## Функциональность

- Генерация JSON-данных для веб-страниц:
  - Главная страница с общей статистикой
  - Страница событий с анализом расходов/доходов
- Сервисы анализа:
  - Выгодные категории кешбэка
  - Инвесткопилка (расчет округлений)
- Отчеты:
  - Траты по категориям
  - Траты по дням недели
